# Ambii

A music app for listening together: everyone's favorite music, with any group, anywhere.

## Preview

`public/projects/ambii/` is the static landing page, copied from the `JakeMotta/ambii_landing_page` repository at commit `41bff74` (2018-10-05). Only the files the page serves are here; its SCSS and gulp sources stay in that repo (`SOURCE.txt` says the same). It runs as-is, with no conversion.

`public/projects/pistol-art/files/` happens to hold an unrelated compiled build of the Ambii web app (React, Auth0, the `hola.ambii.io` API). It isn't wired up to anything, and the preview doesn't use it.

## Card image

`public/images/projects/ambii.webp`, a screenshot of the landing page taken by `yarn projects:screenshot ambii`. The card has no description; that's deliberate rather than missing.
