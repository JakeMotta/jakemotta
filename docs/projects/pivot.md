# Pivot Animations

Stick-figure animations Jake made in Pivot Stickfigure Animator in August and September 2008: fights, sword moves, skate tricks and Goku versus Vegeta. The folder is `public/projects/pivot/`; the card id is `pivot`.

## Preview

`index.html` is a hand-written gallery. The three long fights (ULTAMATE FIGHTER, Goku and Vegeta, Jacob's Fight) run full width, and the rest sit in a grid. Each GIF is a plain link to its file. Clicking one opens it full size in a `<dialog>`, and clicking again closes it.

The GIFs in `animations/` are the originals, copied unchanged with their own names, typos included (`ULTAMATE FIGHTER..gif`, `skate park on gif.gif`). Together they're about 10 MB, so everything below the first one loads lazily.

## Left out on purpose

The archive's `Pivot/Animations` folder holds 18 GIFs. Three aren't here:
- `falsh blue.gif` and `flash green.gif` are two-frame color flashes, not animations.
- `raining men flash blue.gif` is the same animation as `raining men.gif`.

The `.piv` source files and the downloaded figure packs stay in the archive too.
